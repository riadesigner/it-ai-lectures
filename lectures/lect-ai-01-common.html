Как изменились (-ятся) профессии

  • процесс проектирования для архитектора?
  • работа писателя над книгой?
  • работа учёных над написанием научных трудов?
  • процесс проверки сочинения в школе?
  • процесс создания 3D контента для игр?
  • процесс создания диалогов для игровых персонажей?
  • работа врачей?
