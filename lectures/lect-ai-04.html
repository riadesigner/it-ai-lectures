Chain-of-Thought

Что такое CoT

цепочка рассуждений · Thought Generation

  • модель не только выдаёт ответ, но и показывает ход рассуждения
  • в промпт добавляют примеры рассуждения, затем аналогичную задачу
  • заметно повышает качество на математических и логических задачах

CoT · пример

One-shot CoT

Задача: У Джека две корзины, в каждой по 3 мяча. Сколько всего мячей?
Рассуждение: В одной корзине 3 мяча, в двух — 2 × 3 = 6 мячей.
Ответ: 6.

Задача: [новая аналогичная задача]
Рассуждение: ...

На курсе

CoT для gamedev

«покажи черновик», а не только финал

  • полезно для баланса, условий победы, логики головоломок
  • модель объясняет, почему выбрала те или иные параметры
  • аналогия: черновик дизайна квеста, а не только готовый результат

Zero-Shot CoT

Без примеров

триггерная фраза запускает пошаговое рассуждение

  • «Рассуждай шаг за шагом» / «Сначала подумай логически»
  • не нужны примеры — работает на любой задаче
  • эмоциональный триггер: «…чтобы не допустить ошибку»

Zero-Shot CoT · техники

Step-Back · Analogical

  • Step-Back — сначала вопрос о общих принципах (закон, формула), потом решение
  • активирует нужные знания; лучше обычного CoT на физике и т.п.
  • Analogical — вспомнить аналогичные задачи из обучения, затем решить новую
  • синтетические примеры рассуждений; хорошо для математики и кода

Zero-Shot CoT · техники

ThoT · Tab-CoT

  • Thread-of-Thought — развёрнутый триггер: «проанализируй, пошагово объясни, обобщай»
  • для вопросов с большим контекстом, RAG, информационного поиска
  • Tabular CoT — оформить рассуждение таблицей Markdown
  • структура при многоступенчатых условиях; меньше токенов (≈140 → ≈28 слов)

Пример · Step-Back

Физика

сначала закон, потом расчёт

  • перед задачей: «Какой физический закон нужен?»
  • модель вспоминает уравнение идеального газа → считает ответ
  • обычный «шаг за шагом» в том же примере может дать ошибку

На курсе

Zero-Shot для gamedev

ThoT + Tab-CoT

  • ThoT — длинный лор-документ, нужно разобрать весь контекст
  • Tab-CoT — таблица «условие → эффект → баланс» для механик

Few-Shot CoT

С примерами рассуждения

Manual CoT · Golden CoT

  • несколько примеров полного рассуждения в промпте
  • если примеры написаны человеком — Manual CoT или Golden CoT
  • точнее zero-shot, но требует подготовки эталонов

Few-Shot CoT

Contrastive CoT

правильные и неправильные примеры

  • в промпт — корректные и ошибочные примеры рассуждения
  • помогает на арифметике и фактологических вопросах
  • для gamedev: показать «плохой» и «хороший» дизайн квеста

Декомпозиция

Decomposition

разбиение на подзадачи

  • сложная задача делится на простые шаги
  • часть техник похожа на CoT (модель сама «дробит» задачу)
  • если пользователь заранее разбивает инструкцию — качество часто выше
  • аналогия: вы составили план уровня, модель заполняет этапы

Декомпозиция · техники

Least-to-Most · Plan-and-Solve

  • Least-to-Most — разбить на подзадачи → решать по очереди, добавляя ответы в промпт
  • символьные преобразования, обобщение (саммари)
  • Plan-and-Solve — «сначала план, потом выполни план шаг за шагом»
  • улучшенный zero-shot CoT; меньше логических ошибок

Декомпозиция · техники

ToT · Recursion-of-Thought

  • Tree-of-Thought — дерево вариантов: несколько первых шагов → выбор лучшего → ветвление
  • для планирования и стратегий
  • Recursion-of-Thought — сложная подзадача уходит в отдельный промпт, результат вставляется обратно
  • обход лимита контекста; часто нужен спец. токен или текстовый аналог

Декомпозиция · техники

Faithful · Skeleton · Metacognitive

  • Faithful CoT — рассуждение на NL + код; инструкция → функция → исполнение
  • Skeleton-of-Thought — «скелет» подзадач → параллельная обработка → сборка
  • Metacognitive Prompting — пять этапов: уточнение → черновик → оценка → стратегия → уверенность
  • самопроверка и рефлексия

Metacognitive Prompting

Пять шагов

  • 1. Уточнить вопрос
  • 2. Первичное решение
  • 3. Оценить первичное решение
  • 4. Выбрать итоговую стратегию
  • 5. Оценить уверенность

На курсе

Декомпозиция для gamedev

практические применения

  • Least-to-Most — «сначала механика, потом UI, потом баланс»
  • ToT — ветвящийся сюжет
  • Skeleton-of-Thought — параллельная генерация веток диалога по пунктам плана

CoT vs декомпозиция

Когда что использовать

  • одна логическая/математическая задача → Zero-Shot или Few-Shot CoT
  • нужны общие принципы перед расчётом → Step-Back
  • много контекста, RAG, длинный документ → ThoT, Tab-CoT
  • сложная многошаговая инструкция → Least-to-Most, Plan-and-Solve
  • планирование с ветвлениями → Tree-of-Thought
  • очень длинная цепочка, лимит контекста → Recursion-of-Thought
  • самопроверка ответа → Metacognitive Prompting, Contrastive CoT

Частая ошибка

Только «шаг за шагом»

неявные зависимости между шагами

  • на задаче с неявными зависимостями простой CoT может не хватить
  • лучше явный план — Plan-and-Solve
  • или разбиение — Least-to-Most
