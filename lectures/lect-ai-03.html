Промпт-инжиниринг

ключевые термины и базовые техникиавг 2026

Введение

Hard prompting

префиксные промпты на естественном языке

  • термин «промпт-инжиниринг» распространился в сети с 2021 года
  • промпт = ТЗ для модели; шаблон = форма под разные входы

Термины

Шаблон vs экземпляр

prompt template · prompt instance

  • шаблон — заготовка с переменными для повторного использования
  • экземпляр — конкретный запрос после подстановки данных
  • шаблон — инструмент мышления: ничего не забыть, задача чёткая

Пример · шаблон

План тренировок

Ты — профессиональный фитнес-тренер.
Составь план тренировок для [ЦЕЛЬ: похудение / набор массы / поддержка тонуса].
Уровень подготовки: [НАЧАЛЬНЫЙ / СРЕДНИЙ / ПРОДВИНУТЫЙ].
Доступный инвентарь: [СПИСОК].
Количество тренировок в неделю: [ЧИСЛО].

Ответ дай в виде списка по дням недели.
Каждое упражнение опиши в 1 предложении.
Общая длительность одной тренировки — не более [ВРЕМЯ] минут.

Структура промпта

Компоненты

универсальный набор из 6 частей

  • роль — кем «быть» модели (narrative designer, баланс-дизайнер)
  • директива / задача — явная инструкция или вопрос
  • примеры — образцы выполнения (one-shot, few-shot)
  • формат выдачи — CSV, Markdown, JSON, таблица
  • инструкции по стилю — тон, лаконичность, жанр
  • доп. информация — сеттинг, имена, ограничения проекта

Связь с лекцией 2

RCTF ↔ компоненты

одна схема — разные названия

  • Role → роль · Context → доп. информация
  • Task → директива · Format → формат выдачи
  • Constraints → стиль + ограничения
  • частая ошибка: только «придумай квест» без формата и контекста

Термины

Промптинг vs инжиниринг

разговор vs отладка рецепта

  • промптинг — любое взаимодействие с моделью через промпты
  • цепочка промптов — ответ первого → вход для второго
  • техника промптинга — схема построения промпта или цепочки
  • промпт-инжиниринг — итеративный поиск: тест → оценка → правка

Промпт-инжиниринг

Цикл из 3 шагов

  • прогнать промпт на наборе примеров (квесты, NPC-реплики)
  • оценить качество: формат, лор, играбельность
  • отредактировать шаблон и повторить · A/B промптов, итерация по RCTF

Обзор техник

Текстовые техники

The Prompt Report · 6 категорий

  • Few-Shot · Zero-Shot · Chain-of-Thought
  • Ensembling · Self-Criticism · Decomposition
  • в этой лекции — few-shot и zero-shot;
  • всего насчитвается ~ 58 текстовых техник

In-Context Learning

ICL

адаптация без обновления весов

  • модель подстраивается под задачу за счёт примеров и инструкций в промпте
  • нужна конкретная инструкция, чтобы активировать нужное поведение
  • meta-learning шире — на этапе pre-training; ICL — в одном запросе

Few-shot

Few-shot промптинг

примеры «вход → выход» в промпте

  • несколько примеров помогают уловить закономерность
  • разновидность few-shot learning, но без дообучения модели
  • few-shot = 2–3 образца диалога NPC в нужном тоне
  • zero-shot = только инструкция «пиши как смотритель маяка»

Few-shot · шаблон

Базовая схема

Пример 1: {вход} → {выход}
Пример 2: {вход} → {выход}
Задача: {тестовый вход} → ?

Few-shot · отбор примеров

Принципы 1–3

  • количество — больше часто лучше; >20 может не помочь или ухудшить
  • порядок — перестановка может менять точность (50% → 90%)
  • распределение меток — перекос → предвзятые ответы

Few-shot · отбор примеров

Принципы 4–6

  • качество меток — крупные модели устойчивее к шуму
  • формат — единый (`Q: … A: …`), ближе к обучающим данным
  • инструкция — иногда достаточно только примеров; лишняя может снизить качество
  • ошибка: 10 примеров «как попало» → нестабильный результат

Zero-shot

Zero-shot промптинг

без примеров — только инструкция

  • роль, стиль, контекст — по необходимости
  • когда zero-shot: быстрый черновик, широкая задача, нет эталонов
  • когда few-shot: строгий формат, тон, классификация по образцу

Zero-shot · техники

Role · Style · Emotion

  • Role / Persona — «ты — narrative designer indie-RPG…»
  • Style — задать тон, жанр без смены роли
  • Emotion — психологические триггеры («Это важно для моей карьеры»)

Zero-shot · техники

S2A · SimToM · RaR

  • S2A — сначала очистить промпт от лишнего, потом ответ
  • SimToM — «Что знает персонаж X?» → ответ с его точки зрения
  • RaR — перефразируй и уточни вопрос, затем ответь

Zero-shot · техники

RE2 · Self-Ask

  • RE2 — добавить «Ещё раз прочитай вопрос»
  • Self-Ask — модель задаёт уточняющие вопросы, потом финальный ответ

Пример · SimToM

Ложные убеждения

не путать знание персонажа с фактом

  • «Джим положил мяч в коробку. Ави переложил в корзину»
  • шаг 1: «Что знает Джим?» · шаг 2: «Где мяч по мнению Джима?»
  • для gamedev: NPC не знают событий off-screen

На курсе

Zero-shot для gamedev

практические применения

  • Role — «ты гейм-дизайнер roguelike на мобилках»
  • Style — «реплики по 1 предложению, без modern сленга»
  • RaR / Self-Ask — размытый бриф от продюсера: сначала уточнить scope
